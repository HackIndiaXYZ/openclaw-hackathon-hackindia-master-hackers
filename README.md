# 📚 AI Study Planner

## 🚀 Overview
AI Study Planner is a simple web app that helps students plan their daily study schedule based on available hours.

## ✨ Features
- 📊 Automatic subject time division
- 📅 Daily study routine suggestion
- ✅ Progress tracking with checkboxes
- 🎯 Simple and clean UI

## 🛠️ Tech Used
- HTML
- CSS
- JavaScript

## 💡 How It Works
1. Enter number of study hours
2. Click "Generate Plan"
3. Get subject-wise study plan
4. Track your progress using checkboxes

## 📌 Future Improvements
- Add AI-based smart recommendations
- Save daily progress
- Add login system
